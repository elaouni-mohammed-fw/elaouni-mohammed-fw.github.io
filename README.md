# Mohammed El Aouni — Cybersecurity Portfolio

English static portfolio matching the supplied reference's layout, Poppins typography, navy background, electric-blue accents, rotating portrait ring, timeline, skills cards, project cards and contact section.

## Preview

Extract the archive and open `index.html` in your browser. No installation or build step is required.

## GitHub Pages

1. Create a public repository named `elaouni-mohammed-fw.github.io` (or use a repository named `portfolio`). Back up any existing repository contents before replacing them.
2. Upload the contents of this archive to the repository root, including `index.html`, `style.css`, `script.js`, `assets/` and `.nojekyll`. Do not upload the ZIP itself.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch → main → /(root) → Save**.
5. After deployment, use the site URL shown by GitHub Pages.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Contact form

**Send Message** opens the visitor's email application with a prepared message. The visitor must review and send it there. No message is sent automatically. Name, valid email and message fields are required.

Keyboard focus indicators, labelled form fields, mobile menu state, skip link and reduced-motion preferences are supported. Content remains readable without JavaScript.
